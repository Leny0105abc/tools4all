TOOLS4ALL LOCAL VIDEO DOWNLOADER FOR WINDOWS

1. Extract every file from this ZIP into one folder.
2. Double-click "Start Tools4All Downloader.cmd".
3. Paste a YouTube video or Shorts URL.
4. Choose a save folder and confirm you have permission to save the video.
5. Select "Download MP4".

This companion runs on your own computer and internet connection. It is intended
only for videos you own or have permission to save. Availability can change when
video services update their systems.

Keep yt-dlp.exe and deno.exe in the same folder as the launcher.

The included yt-dlp.exe is the official Windows release from:
https://github.com/yt-dlp/yt-dlp

The included deno.exe is the official Windows release from:
https://github.com/denoland/deno
